# ワンたす 法務・サポートページ

公開対象は静的HTML/CSSのみです。アプリ本体のコード、外部フォント、解析タグ、広告タグ、Cookieを含みません。

## 公開URL

- `https://wantasu.sfdig.jp/privacy/`
- `https://wantasu.sfdig.jp/support/`
- GitHub Pages一時URL: `https://hanamarunago-star.github.io/wantasu-legal/privacy/`
- GitHub Pages一時URL: `https://hanamarunago-star.github.io/wantasu-legal/support/`

## GitHub Pages

GitHub Pagesの公開元を `main` ブランチの `/ (root)` に設定します。カスタムドメインは `wantasu.sfdig.jp` です。ルートの `CNAME` ファイルにも同じドメインを記載しています。

DNS設定はこのリポジトリでは行いません。GitHub Pagesでカスタムドメインの設定が完了した後、表示される案内と一致するDNS値を確認してからドメイン管理側で設定してください。

## 内容更新時の確認

- アプリの保存先、送信先、機能とポリシーが一致していること
- 問い合わせメールアドレスが現行であること
- プライバシー／サポート両ページのリンクが機能すること
- 個人情報、鍵、認証情報、アプリコードを含めないこと
